# 영어 통화 연습 (English call practice)

전화와 화상 미팅 영어를 AI 상대와 연습하는 개인용 웹앱이에요.

- 14일 코스: 자기소개, 숫자 설명, Upwork 미팅, 미국 회사에 전화하기, 번역 품질 피드백, 모의시험
- 실시간 음성 대화: Google Gemini Live API
- 통화가 끝나면 한국어 피드백과 점수, 외울 표현을 보여 줘요

## 개인정보
- API 키와 연습 기록은 사용하는 기기의 브라우저에만 저장돼요. 이 사이트에는 서버가 없어요.
- 무료 등급 키를 쓰면 대화 내용이 구글 서비스 개선에 쓰일 수 있어요. 회사 기밀이나 고객 정보는 말하지 마세요.
- 화상 미팅 모드의 카메라 화면은 기기에서만 보이고 AI에게 보내지 않아요.
